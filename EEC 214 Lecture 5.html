Linear Regulators¶

NONIDEAL OPAMP LINEAR REGULATOR¶

Source Follower with Resistive Feedback

$$v_o = A_v(v_+ - v_-)$$

$v_o$ saturates for large $\vert{}v_+ - v_-\vert{}$

$$v_o = G_m \left(R_o \vert{}\vert{} \frac{1}{C_o s}\right) (v_+ - v_-) \qquad \qquad A_v = G_m \frac{R_o / C_o s}{R_o + \frac{1}{C_o s}} = \frac{G_m R_o}{1 + R_o C_o s}$$

(Bode magnitude plot of opamp transfer function showing single-pole rolloff starting at cutoff frequency 1.6 kHz.)

$$\left. \begin{aligned} V_G &= A_v(V_{REF} - V_f) = A_v\left(V_{REF} - \frac{R_2}{R_1 + R_2} V_{out}\right) \\ I_{DS} &= I_L + \underbrace{\frac{V_{out}}{R_1 + R_2}}_{\substack{\text{assume big} \\ \text{implies current} \\ \text{small}}} \approx I_L = \frac{\mu_n C_{ox}}{2} \left(\frac{W}{L}\right)_{N0} (V_{GS} - V_{T,n})^2 \\ V_{out} &\approx \left(1 + \frac{R_1}{R_2}\right) \left[ V_{REF} - \frac{1}{A_v} \left( \sqrt{\frac{I_{out}}{\frac{\mu_n C_{ox}}{2} \left(\frac{W}{L}\right)_{N0}}} + V_{T,n} \right) \right] \end{aligned} \right\} \text{Earlier Solution}$$
  • At low frequency, $A_v = G_m R_o$, so
$$V_{out} \approx \left(1 + \frac{R_1}{R_2}\right) \left[ V_{REF} - \frac{1}{G_m R_o} \sqrt{\frac{I_{out}}{\frac{\mu_n C_{ox}}{2} \left(\frac{W}{L}\right)_{N0}}} - \frac{V_{T,n}}{G_m R_o} \right]$$$$\lim_{G_m R_o \rightarrow \infty} V_{out} = \left(1 + \frac{R_1}{R_2}\right) V_{REF}$$
  • At high frequency, $\displaystyle A_v = \frac{G_m R_o}{1 + R_o C_o j\omega} \rightarrow A_v \approx \frac{G_m}{j\omega C_o} \rightarrow 0 \text{ as } \omega \rightarrow \infty$
$$V_{out} \approx \left(1 + \frac{R_1}{R_2}\right) \left( V_{REF} - \frac{j\omega C_o}{G_m} \left( \sqrt{\frac{I_{out}}{\frac{\mu_n C_{ox}}{2} \left(\frac{W}{L}\right)_{N0}}} + V_{T,n} \right) \right)$$

Bandwidth of linear regulator is set by bandwidth of opamp, if $C_{GS}$ of power FET can be neglected.

Not often true if $I_L$ can be large (need $W/L$ ratio for $N0$ large also).

NMOS Power FET Design¶

Solving for NMOS $\frac{W}{L}$ ratio as a function of output (load) current and desired overdrive voltage:

$$ \left(\frac{W}{L}\right)_{\textrm{N0}} = \frac{I_{out}}{V_{ov}^{2} \frac{\mu_{N} C_{ox}}{2}} $$

Single-Stage Op Amp

$$\text{Differential gain } A_d = G_m R_o = g_{m,N1} (r_{o,N1} || r_{o,P0}) = A_v$$$$g_{m,N1} = \sqrt{2 \mu_n C_{ox} \frac{W}{L} I_D} = \sqrt{2 \mu_n C_{ox} \left(\frac{W}{L}\right)_{N1} \frac{I_{TAIL}}{2}} = \sqrt{\mu_n C_{ox} \left(\frac{W}{L}\right)_{N1} I_{TAIL}}$$$$r_{o,N1} = \frac{1}{\lambda_n I_D} = \frac{2}{\lambda_n I_{TAIL}}$$$$r_{o,P0} = \frac{1}{\lambda_p I_D} = \frac{2}{\lambda_p I_{TAIL}}$$

# 180 nm CMOS Transistor Parameters
# ---------------------------------
muCoxN = 387e-6 # NMOS process transconductance (A/V^2)
Vt0N   =    0.5 # NMOS nominal threshold voltage (V)
VAprimeN =    5 # NMOS Early voltage parameter (V/um)    

muCoxP =  86e-6 # PMOS process transconductance (A/V^2)
Vt0P   =   -0.5 # PMOS nominal threshold voltage (V)
VAprimeP =    6 # NMOS Early voltage parameter (V/um) 

# Bias Current
# ------------
Itail  = IQspec / 2 # Allocate half the quiescent current to opamp bias current. Good idea?

# NMOS Differential Pair
# ----------------------
LN1 = 0.27          # Channel length (nonminimum) (um)
VAN1 = VAprimeN*LN1 # Early voltage (V)
print("NMOS N1 Early voltage (nonminimum length) = {0:7.3f} (V)".format(VAN1))

# Determine NMOS differential pair FET width.

Vov   = 0.1 # Overdrive (V)

WN1 = LN1*((Itail/2)*1.0e-3/((Vov**2)*(muCoxN/2)))
print("\nNMOS N1 width = {0:7.3f} (um)".format(WN1))

gmN1 = sqrt(muCoxN*(WN1/LN1)*Itail*1e-3)
print("\nNMOS N1 gm = {0:7.3f} (uA/V)".format(gmN1/1e-3))

roN1 = VAN1/((Itail/2)*1.0e-3)
print("\nNMOS N1 ro = {0:7.3f} (ohms)".format(roN1))

# Calculate gain assuming PMOS P0 output resistance same as NMOS N1 (for now)
Av0 = gmN1*(roN1/2)
print("\nOpamp Gain Av = {0:7.3f} (V/V)".format(Av0))

# Calculate output voltage with one-stage opamp gain
Vo = (1+R1/R2)*( VREF - (1/Av0)*(sqrt(ILmax*1e-3 / ((muCoxN/2)*(WN0/LN0)) ) + Vt0N) )

print("\nOutput voltage (single-stage finite opamp gain) = {0:8.12f} (Vo)".format(Vo))

SHUNT REGULATOR¶

Adjust $I_{shunt}$ s.t. $V_{out} = V_{in} - R_{in}(I_L + I_{shunt}) = V_{REF}$

Need $V_{in} - R_{in} I_{L,max} \ge V_{REF}$ since $I_{shunt} \ge 0\text{ A}$.

$$\text{Best case efficiency : } V_{in} - R_{in} I_{L,max} = V_{out}$$

$$P_{out} = V_{out} I_{L,max}$$$$P_{in} = V_{in} I_{L,max}$$

$$P_{in} = V_{out} I_{L,max} + I_{L,max}^2 R_{in}$$$$\eta = \frac{P_{out}}{P_{in}} = \frac{V_{out} I_{L,max}}{V_{out} I_{L,max} + I_{L,max}^2 R_{in}}$$$$\phantom{\eta = \frac{P_{out}}{P_{in}}} = \frac{1}{1 + \frac{I_{L,max} R_{in}}{V_{out}}} = \frac{1}{1 + \frac{R_{in}}{R_{L(min)}}}$$

High-Voltage Tolerant FETs¶

FET structures modified to limit the electric field due to the applied voltages to be below the critical (breakdown) field.

Drain-Extended MOS (DEMOS)¶

Lateral field from drain to source is (mostly) dropped across drain-extended diffusion region.

Tradeoff between maximum $V_{DS}$ and on resistance of the MOSFET.

Increasing the drain extension length increases both. (Also increases device area and increases drain junction parasitic capacitance).

Typical Maximum Voltages:

  • Maximum gate-source voltage $V_{GS\textrm{,max}} \geq V_{GS}$
  • Maximum gate-drain voltage $V_{GD\textrm{,max}} \geq V_{GD}$ and $V_{GD\textrm{,max}} > V_{GS\textrm{,max}}$
  • Maximum drain-source voltage $V_{DS\textrm{,max}} \geq V_{DS}$

Often set by oxide breakdown limitations

Lateral Double-Diffused MOS (LDMOS)¶

LDMOS structure has advantage of low on-resistance and high drain-source and/or gate-drain breakdown voltages.

Often applied to RF power amplifier designs

Double-Diffused Drain MOS (DDDMOS)¶

Symmetric structure compared to DEMOS.
